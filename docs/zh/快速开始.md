# 快速开始与排错

> 假设你已经用上游 [arch-xiaomi-pad8](https://github.com/KoryoSony/arch-xiaomi-pad8) 的 `v0.1.0-alpha` 资产把 Arch Linux 装到平板。本仓库只替换**内核**。

## 1. 确认前提

```bash
adb shell getprop ro.build.display.id          # 需要 OS4.0.5.0.XPZCNXM
adb shell getprop ro.boot.vbmeta.device_state  # 需要 unlocked
```

底包不是 4.0.5 的机器，`/vendor` 里的模块与这个内核不匹配，不要刷。

## 2. 刷内核

```bash
adb reboot bootloader
fastboot flash boot boot.img     # 从 Releases 下载
fastboot reboot
```

只刷活动槽的 `boot`，不要动 `vbmeta`，不要动另一槽，保底可回退。

校验（可选）：

```bash
sha256sum boot.img
```

## 3. 开机后跑装机脚本

```bash
git clone https://github.com/wrightgilbert/pad8-arch-linux-flatpak
bash pad8-arch-linux-flatpak/scripts/post-install.sh
```

脚本做三件事：

1. `chmod 755 /usr/bin/bwrap` —— 上游镜像里的 bubblewrap 带 setuid 位，而我们提供了 `USER_NS`，setuid 模式会被 bubblewrap 自己拒绝；
2. 添加 Flathub 源；
3. 跑 `scripts/verify.sh` 自检（内核版本、四个 `CONFIG_*`、user namespace、`/proc/sysvipc`、bwrap 权限、沙箱内挂 `/proc`、模块数量、dmesg 里的 CRC 冲突）。

## 4. 验证

```bash
flatpak install --user flathub org.gnome.Calculator
flatpak run org.gnome.Calculator
```

自检单独跑：

```bash
bash pad8-arch-linux-flatpak/scripts/verify.sh
```

## 排错

| 症状 | 原因 | 处理 |
|---|---|---|
| 卡在开机 Logo，USB 也不出 | 内核起来了但模块全都加载不了（补丁没生效，或底包不对） | 刷回上游 `boot.img`，确认底包是 4.0.5 |
| `bwrap: setuid use of bubblewrap is not supported` | `/usr/bin/bwrap` 还带 setuid | `sudo chmod 755 /usr/bin/bwrap` |
| `bwrap: Can't mount proc on /proc: Operation not permitted` | 内核缺 `0003` | 确认 `uname -r` 是本仓库提供的内核 |
| `flatpak run` 报 `ldconfig failed` | 沙箱没起来，后续命令连带失败 | 先解决上一条 |
| 装 GNOME 运行时很慢 | Flathub 运行时约 2.5 GB | 正常 |

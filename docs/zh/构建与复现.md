# 自己编译（aarch64 主机）

在平板本机上编约 10 分钟，树莓派 5 之类的机器也能编，慢一些。磁盘预留 20-25 GB。

## 1. 装依赖、取编译器

上游移植的 `config.sh` 钉的是 AOSP 的 `clang-r510928`，但那份工具链已经从 AOSP 仓库移除，直接用 LLVM 官方的同版本即可：

```bash
# Arch
sudo pacman -S --needed base-devel bc bison flex libelf cpio rsync git curl zstd lz4 python

mkdir -p ~/llvm18 && cd ~/llvm18
curl -LO https://github.com/llvm/llvm-project/releases/download/llvmorg-18.1.8/clang%2Bllvm-18.1.8-aarch64-linux-gnu.tar.xz
tar -xf clang+llvm-18.1.8-aarch64-linux-gnu.tar.xz --strip-components=1
clang --version | head -1
```

## 2. 补两个编译环境的小坑

`ld.lld` 需要 `libxml2.so.2`，Arch 只提供 `libxml2.so.16`：

```bash
sudo ln -sf /usr/lib/libxml2.so /usr/lib/libxml2.so.2
```

`resolve_btfids` 在 Arch 的 asm 头下编不过，直接关掉 BTF（不影响启动和模块）：

```bash
# build-kernel.sh 会自动往配置片段里写这一行
# CONFIG_DEBUG_INFO_BTF is not set
```

## 3. 编译

```bash
git clone https://github.com/KoryoSony/arch-xiaomi-pad8
git clone https://github.com/wrightgilbert/pad8-arch-linux-flatpak

cd arch-xiaomi-pad8
PORT=$PWD TC=$HOME/llvm18 PATCHES=../pad8-arch-linux-flatpak/patches \
    bash ../pad8-arch-linux-flatpak/scripts/build-kernel.sh
```

脚本会：拉内核 `android15-6.6-2026-01_r37` → 打 `patches/0001..0003`（幂等）→ 往 `kernel/yupei-linux.fragment` 追加四个命名空间相关的 `CONFIG_*` → 调上游 `kernel/build-kernel.sh` → 产物落在 `out/`（`Image`、`Module.symvers`、`.config`、`kernel.release`）。

## 4. 换内核进 boot.img

```bash
python ../pad8-arch-linux-flatpak/scripts/mkboot.py \
    --base boot.img --kernel out/Image --out boot-flatpak.img
```

`--base` 用上游 release 的 `boot.img`（v4、无 ramdisk、无签名）。脚本只改头部里的 `kernel_size`，其余字段原样保留。

## 5. 刷机与验证

```bash
adb reboot bootloader
fastboot flash boot boot-flatpak.img
fastboot reboot
```

开机后：

```bash
bash pad8-arch-linux-flatpak/scripts/post-install.sh
```

## 在 x86_64 主机或 CI 上编

需要额外的 ncurses 兼容软链（官方 x86_64 tarball 构建于 Ubuntu 18.04，依赖 `libtinfo.so.5`）：

```bash
sudo ln -sf /lib/x86_64-linux-gnu/libtinfo.so.6 /lib/x86_64-linux-gnu/libtinfo.so.5
sudo ln -sf /lib/x86_64-linux-gnu/libncurses.so.6 /lib/x86_64-linux-gnu/libncurses.so.5
sudo ln -sf /lib/x86_64-linux-gnu/libncursesw.so.6 /lib/x86_64-linux-gnu/libncursesw.so.5
sudo ldconfig
```

仓库不附 GitHub Actions workflow：这条链路在 x86_64 容器里没有走完，aarch64 上已验证可用。
